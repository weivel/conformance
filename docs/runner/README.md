The runner is `weivel-conformance`, a C program in this repository, and this folder is its contract with whoever writes an adapter for it. `weivel-conformance run <directory>` walks a directory of vectors, asks an adapter for each vector's answer, judges the answer against the vector's `then`, and reports. The vectors live here, outside every implementation, so that no implementation defines its own exam. The exit code is 0 only when at least one vector ran and every vector passed, 1 when any did not, and 2 when the corpus is refused or the command is misused. A corpus is refused, before anything runs, when it holds no vector, a file that is not JSON, an op the kit does not know, a vector asserting nothing, an id declared twice, or an id whose family is not its op. Read this folder before writing an adapter; what the vectors themselves hold is in [the vectors' docs](../vectors/README.md).
