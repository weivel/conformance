The repo root of the conformance kit: one CMake project in C11 that builds the runner, the drift checks, the core control call benchmark, the stub provider `stub-host` and the kit's tests. It builds nothing of weivel itself: configuring refuses to start unless the core is checked out at `siblings/core` and the standard at `siblings/standard` (a clone, a directory junction or a symlink, at the commits `repo.json` pins), and adds both as subdirectories, so every adapter links the very core and standard the kit is pinned to. Every target of the kit's own is built with warnings as errors (`/W4 /WX /utf-8` on MSVC, `-Wall -Wextra -Wpedantic -Werror` elsewhere), and programs and libraries land in the build's `bin` directory. Beside the unit tests it registers `core_sits_its_vectors` and `standard_sits_its_vectors`, which run `weivel-conformance` over `vectors/core` and `vectors/standard`, so a pin that breaks a vector fails the kit's own suite. Build and test with `cmake -S . -B build`, `cmake --build build --config Debug` and `ctest --test-dir build --output-on-failure -C Debug`; `build/bin/weivel-conformance run vectors` runs the whole corpus by hand.
