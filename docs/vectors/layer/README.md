A vector under `vectors/layer/` states something only a language layer can witness, because the core never calls a listener, never throws and never runs host code. No adapter in the runner runs them ([tiers](../tiers.md)): each language's own layer suite must contain a test that witnesses every vector in that directory, naming it by id, its path under `vectors/layer/` without `.json`. Each suite is described in its language's repository: C's in `docs/conformance.md`, Java's in `docs/modules/conformance.md` and TypeScript's in `docs/source/test/conformance/`, and weivel's `docs/languages/structure.md` links all three. The kit's `layers` drift check fails a language whose tests name one nowhere. The one exception is a directory of vectors that ask for something a language's layer does not do by design: `checks/languages.txt` names it for that language with a `layer-exempt` line, and `layers` then asks for none of its vectors and refuses the line once no vector lies under it. Today there are two: `description/binding/`, which C is exempt from because a C plugin reads a definition through its header and binds nothing (see [the `description` op](description.md)), and `host/`, which C and Java are exempt from because only a language that ships a host program sits it, and TypeScript is the one that does (see [the `host` op](host.md)).
